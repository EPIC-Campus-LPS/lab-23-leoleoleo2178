**Binary Search Tree** 
---


A binary search tree is a type of list where it makes a pyramid where if a value is added to the list it goes below other values already in the list. The tree sorts the list by making it so only values greater then value can go right of it. So all the smaller object in  the list go to the left and vice versa.

**Usage**
---


The usage of a BST(binary search tree) is to enable a fast and efficient way to store data. it makes it so at its slowest it take O(log N) which means it at it's slowest takes log N to find a thing in the list and n represents the length of the list.
